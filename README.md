# Реализация публикации новости 

В данном репозитории показана реализация публикации определенной новости в ленту событий. Показана только Backend часть.

Здесь реализованы два микросервиса которые отправляют сообщение в брокер и сервис который читает сообщения из брокера.

Данный код является частью коммерческого проекта.
